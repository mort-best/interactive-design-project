# Interactive Grid

브라우저에서 체험하는 3D 인터랙티브 작품입니다. 화면을 가득 채운 촘촘한 격자의 작은 3D 오브젝트(구, 둥근 큐브, 링)를 마우스나 손으로 헤치면, 주변 오브젝트가 크게 튕기고 회전하며 흩어졌다가 천천히 원래 자리로 돌아옵니다.

Vite + TypeScript + Three.js로 만들어졌고, 서버나 DB 없이 정적 파일로 동작합니다.

## 실행 방법

```bash
npm install       # 의존성 설치
npm run dev       # 로컬 개발 서버 (기본 http://localhost:5173)
```

브라우저에서 위 주소를 열면 됩니다. 마우스를 격자 위에서 움직여 보세요.

- **천천히 움직이면** 오브젝트를 부드럽게 밀어냅니다.
- **빠르게 움직이면** 이동 방향으로 더 강한 힘과 회전을 줍니다.
- 마우스가 지나가면 잠깐의 지연 후 각자 원래 위치와 방향으로 탄성 있게(작은 오버슈트 포함) 돌아옵니다.

## 빌드 / 미리보기

```bash
npm run build     # dist/ 로 프로덕션 빌드 (타입 체크 포함)
npm run preview   # 빌드 결과를 로컬에서 미리보기
```

## 배포 (GitHub Pages)

`main` 브랜치에 푸시하면 `.github/workflows/deploy.yml`이 자동으로 빌드 후 GitHub Pages에 배포합니다.

1. 저장소의 **Settings → Pages → Build and deployment → Source** 를 **GitHub Actions** 로 설정합니다.
2. `main` 브랜치에 푸시하면 워크플로우가 실행되고, 완료되면 Pages URL에서 확인할 수 있습니다.

`vite.config.ts`의 `base`는 상대 경로(`./`)라, 프로젝트 페이지(`user.github.io/repo/`)와 사용자 페이지 어느 쪽에서도 에셋이 올바르게 로드됩니다.

## 구조

```
src/
  config.ts      # 색상 팔레트, 격자·물리 튜닝 값
  shapes.ts      # 세 형태(구/둥근 큐브/링)의 지오메트리, 칸마다 형태·색 배치
  look.ts        # 젤리·소프트 레진 재질, 스튜디오 환경 반사, 색이 번지는 접촉 그림자
  collisions.ts  # 손에 밀린 오브젝트와 다른 오브젝트의 부드러운 부딪힘
  gridObject.ts  # 오브젝트 하나의 스프링 복원 + 감쇠 + 충격 물리
  pointer.ts     # 마우스를 월드 평면에 투영, 프레임레이트 독립 속도 계산
  interaction.ts # 충돌 영역(마우스/손) → 오브젝트에 힘을 주는 공통 로직
  hand/          # 웹캠 손 추적 (아래 참고)
  main.ts        # 씬/직교 카메라/조명/창 크기에 맞춘 격자 배치/입력 선택/애니메이션 루프
public/models/   # MediaPipe 손 모델 (hand_landmarker.task)
scripts/         # npm run dev/build 전에 MediaPipe WASM을 public/mediapipe/ 로 복사
```

## 웹캠 손 추적

화면 왼쪽 아래 **카메라 시작**을 누르면 MediaPipe Hand Landmarker로 한 손을 추적합니다.

- 손바닥 중심과 손가락 끝 5개에 보이지 않는 충돌 영역이 있고, 마우스와 같은 힘 계산을 씁니다(`interaction.ts`).
- 카메라 좌표는 거울처럼 좌우 반전됩니다. 떨림은 One Euro 필터로 줄입니다(`HAND` 설정, `config.ts`).
- 손이 보이면 손 입력만 쓰고, 안 보이면 마우스를 씁니다. 손이 사라진 뒤에는 마우스를 다시 움직여야 마우스 입력이 켜집니다.
- 손이 나타나거나 사라질 때는 힘을 0.2~0.25초에 걸쳐 서서히 켜고 끕니다.
- 검출은 Web Worker에서 실행되어 3D 애니메이션을 막지 않고, 느린 기기에서는 검출 빈도를 30→15Hz로 낮춥니다.
- 영상은 브라우저 안에서만 처리되고 전송·저장되지 않습니다. 모델과 WASM도 이 사이트에서 불러옵니다.
  단, MediaPipe 라이브러리 자체가 성능·사용량 지표(영상 아님)를 Google에 보낼 수 있다고 안내하고 있습니다
  (`node_modules/@mediapipe/tasks-vision/README.md`의 Privacy Notice).
- 카메라 권한을 거부하거나 카메라가 없어도 마우스로 그대로 체험할 수 있습니다.
- 주소 끝에 `?delegate=cpu`를 붙이면 GPU 대신 CPU로 검출합니다(확인용).

## 인터랙션 구현 메모

- **위치 복원 스프링 + 감쇠**: 각 오브젝트는 자신의 홈 위치/회전을 기억하고, `a = -k·offset - c·v` 형태의 감쇠 스프링으로 되돌아옵니다. 감쇠를 임계보다 약간 낮게 두어 복귀 시 작은 오버슈트가 생깁니다.
- **입력 속도 기반 충격**: 마우스 속도(월드/초)에 비례해 힘과 회전 충격이 커집니다. 빠른 스와이프일수록 강하게 밀고 더 많이 회전합니다.
- **영향 범위**: 마우스 주변의 보이지 않는 반경(`influenceRadius`) 안의 오브젝트에만 힘이 적용됩니다.
- **화면 밖 이탈 방지**: 홈으로부터의 변위를 `maxDisplacement`로 제한합니다.
- **프레임레이트 독립**: 매 프레임 실제 경과 시간(`dt`)으로 적분하며, 탭 전환 등으로 인한 큰 점프는 상한(`maxDelta`)으로 클램프합니다.
- 실제 오브젝트 간 충돌은 아직 넣지 않았습니다(요청대로 필요해질 때 물리 엔진을 추가할 여지를 남겨둠).

## 재질

- `MeshPhysicalMaterial`로 젤리·소프트 레진 느낌을 냅니다.
  - 투과(transmission), 두께(thickness), 흡수 색(attenuation), 낮은 굴절률(ior 1.36), 부드러운 코팅(clearcoat)을 함께 씁니다.
  - 가장자리를 밝히는 효과도 더했습니다.
- 먹색은 투과 없이 불투명하게 두고, 부드러운 광택으로 형태를 보여줍니다.
- 환경 반사는 크림색 방 안에 큰 소프트박스를 둔 장면으로 만들고, 직사광은 약하게 했습니다.
- 오브젝트 아래에는 색이 번지는 그림자를 한 번에 그리고, 움직이는 오브젝트 위치를 따라가게 했습니다.
- 처음 몇 초 동안 프레임이 느리면, 투과 없이 비슷한 인상을 내는 가벼운 재질로 자동 전환합니다.
  - 주소에 `?quality=high` 또는 `?quality=light`를 붙이면 고정할 수 있습니다.
